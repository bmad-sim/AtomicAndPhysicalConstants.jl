Physical Constants

AtomicAndPhysicalConstants.jl exports a flat set of const values drawn from the active CODATA release. All values are Float64 scalars in the units shown below.

The active release is selected at package-load time via a Preferences.jl setting (default: the most recent release the package ships, currently 2022). See CODATA Releases for how to change it.

The tables below give two names for each quantity. The CODATA Name is the field of the CODATA_release struct that holds the published value, as in CODATA2022.MU_PROTON_SI; the APC Name is the exported constant, as in MU_PROTON. The two differ wherever APC converts the published value before exporting it. A dash in the CODATA Name column marks a constant APC derives from other constants rather than reading from a published table.

G_HELION_NUCLEAR_MAGNETONG_HELIONhelion2010 and later
G_TRITON_NUCLEAR_MAGNETONG_TRITONtriton2006 and later

CODATA/NIST tabulates the neutron, deuteron, helion, and triton g-factors relative to the nuclear magneton $\mu_N = e\hbar / 2m_p$. That is, the published number is

\[g_\text{NIST} = \frac{\mu}{I\,\mu_N}\]

so the proton mass — not the particle's own mass — sets the scale. This means that the equation $a = (g_q-2)/2$ is not valid for these quantities. For this reason, to make code using g-factors cleaner, the APC values of the g-factor are computed from $\boldsymbol{\mu} = g\,\frac{e}{2m}\,\mathbf{S}$, where the particle's own mass sets the scale

\[g_\text{APC} = g_\text{NIST}\,\frac{m_\text{particle}}{m_{\text{proton}}}\]

Gyromagnetic anomalies

Units: dimensionless

The gyromagnetic anomaly is defined as

\[a = \frac{g_q - 2}{2}, \qquad g_q = g\,\frac{e}{q},\]

where $g$ is the signed g-factor in the convention $\boldsymbol{\mu} = g\,\frac{e}{2m}\,\mathbf{S}$ and $g_q$ the g-factor normalized to the particle's own charge q, as in the Thomas–BMT equation. Dividing by q gives the electron ($g<0$, $q=-e$) and the positron ($g>0$, $q=+e$) the same positive anomaly, and the doubly charged helion $a = -4.1841537…$. gyromagnetic_anomaly returns NaN for neutral particles, for which $g_q$ is undefined.
